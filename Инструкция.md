# Учёт рабочего времени преподавателя

Клиент-серверный учебный проект на Python 3.12. Организационная база предметной области — МУИВ; тестовые кафедры, преподаватели и планы вымышлены. Программа не заменяет официальный табель, не начисляет зарплату и не подтверждает внедрение в университете.

## Состав

- client.py — настольный клиент, 19 рабочих оконных форм, редакторы записей и вход.
- server.py — JSON API, сессии, проверка доступа.
- storage.py, schema.sql — SQL-хранилище, операции и целостность.
- domain.py — интервалы, единицы измерения и предметные проверки.
- exports.py — DOCX, XLSX, CSV, чтение шаблона импорта.
- quality.py — контроль данных, календарь и поиск.
- maintenance.py, restore.py — блокировка экземпляра и восстановление.
- economics.py — воспроизводимый сценарный экономический расчёт.
- test_system.py — 19 интеграционных проверок.
- Сборка.ps1 — сценарий подготовки Windows EXE; поддерживает выбор Python и виртуального окружения, проверяет Tcl/Tk и результаты каждого этапа.
- tk_support.py — настройка путей Tcl/Tk в Windows.
- startup_check.py — проверка запуска упакованного клиента и загрузки его форм.
- launcher.py, process_group.py — общий запуск, подготовка базы и управление дочерними процессами.
- requirements-build.lock.txt — версии зависимостей выполненной сборки.

## Быстрый запуск из исходников

Для обычной работы с готовой поставкой откройте «Запустить программу.exe» в корне комплекта. Подготовка базы, выбор свободного локального порта и запуск сервера выполняются автоматически. Закрытие клиента завершает сервер. Следующие команды нужны только для работы с исходниками.

Установите Python 3.12 с Tkinter. В Windows при установке Python компонент Tcl/Tk должен быть включён. В Linux необходим пакет Tkinter и графическая среда.

1. Откройте терминал в каталоге проекта.
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. Для первого демонстрационного запуска выполните `python server.py --demo`.
4. В другом терминале выполните `python client.py`.
5. Введите адрес `http://127.0.0.1:8765` и учебные данные.

| Логин | Роль | Доступ |
|---|---|---|
| admin | Администратор | Справочники, учётные записи, настройки, все данные |
| head | Руководитель | Учебная кафедра А |
| teacher | Преподаватель | Тестовый преподаватель 01 |
| teacher2 | Преподаватель | Тестовый преподаватель 07, кафедра Б |

Демонстрационный пароль `admin`: `12345`. Для `head`, `teacher`, `teacher2`: `DemoTime2026!`. Учебную базу нельзя использовать с реальными данными и этими паролями.

При последующих запусках сервера не указывайте `--demo`: `python server.py`. Для отдельной новой базы укажите путь: `python server.py --db data/new.sqlite --demo`.

## Первоначальная настройка без демонстрационных данных

В пустой базе выполните `python server.py --db data/production.sqlite --init`. Пароль администратора вводится в терминале без сохранения в командной строке. Далее войдите под admin и создайте кафедры, преподавателей, виды работ и пользователей. Не включайте в учебную поставку рабочие персональные данные.

Локальный HTTP доступен только на обратном адресе. Для сетевого запуска серверу нужны `--host`, `--cert`, `--key`; клиенту — доверенный HTTPS-адрес. Самоподписанный недоверенный сертификат автоматически не принимается. Для работы в организации требуются её собственные регламенты защиты и администрирования.

## Порядок учёта

1. Администратор заполняет справочники.
2. Руководитель задаёт месячный план по преподавателю и виду работы.
3. Преподаватель добавляет фактический интервал в пределах одного дня.
4. Проверенная запись передаётся на согласование.
5. Руководитель согласует или возвращает с обязательным комментарием.
6. В отчётный факт включаются только согласованные записи.
7. Администратор закрывает период после согласования всех записей.

Интервалы одного преподавателя в один день не пересекаются. Общая граница двух соседних интервалов допустима. Изменение устаревшей версии отклоняется. Согласованный факт нельзя редактировать обычной операцией.

Академические и астрономические часы не смешиваются. Первичные минуты пересчитываются после суммирования; демонстрационный академический час равен 45 минутам. Показатель недельной продолжительности не используется для автоматического начисления зарплаты.

## Импорт и экспорт

Шаблон CSV создаётся в форме «Импорт записей». Колонки: `teacher_id;workday;start;end;type_id;title;evidence`. Разделитель — точка с запятой, кодировка UTF-8. Сначала выполняется проверка без изменения базы. Любая ошибка при загрузке откатывает весь набор. Строки загружаются как черновики.

Отчёт сохраняется на компьютере пользователя в DOCX, XLSX или CSV. Документы DOCX и XLSX содержат примечание о проектной базе; CSV содержит табличные строки. Перед передачей отчёта проверьте выбранный период и доступные пользователю сведения.

## Резервное копирование

Администратор создаёт копию кнопкой «Резервная копия» в настройках. Файл появляется в каталоге backups рядом с серверной базой. Используется SQLite Backup API, затем проверка целостности. Копии следует хранить и на отдельном защищённом носителе по регламенту организации.

Для восстановления остановите сервер и выполните `python restore.py ПУТЬ-К-КОПИИ --db data/worktime.sqlite`. Утилита проверит схему, целостность и внешние ключи, запросит подтверждение, сохранит текущую базу и заменит её проверенной копией. Блокировка экземпляра препятствует восстановлению поверх работающего сервера.

## Проверки

`python -m unittest -v test_system.py` — интеграционные проверки. Они создают временные базы и локальный HTTP-сервер. Требуются зависимости экспорта. `python economics.py` — исходные допущения и результаты экономического расчёта. Оценка высвобождаемой трудоёмкости не является фактической прибылью МУИВ.

## Передача и ограничения

В поставке находятся исходные файлы, сценарий сборки и готовые Windows EXE. Проверка актуальных сборок на Windows 11 выполнена 18 октября 2026 года; результаты приведены в каталоге «Протоколы» и в файле «Протокол проверки.md» в корне комплекта. Сборки размещены в каталогах «Клиент» и «Сервер»; каждый каталог следует переносить целиком вместе с _internal. Общий запуск находится в «Запустить программу.exe». Публикация исходников в репозитории в текущую проверку программного комплекта не входила.

Для повторной сборки откройте PowerShell в каталоге «Исходники» и выполните `& '.\Сборка.ps1'`. Требуется Python 3.12 с Tcl/Tk. Если Python отсутствует в PATH, укажите `& '.\Сборка.ps1' -PythonExe 'ПОЛНЫЙ-ПУТЬ-К-python.exe'`. Для существующего окружения доступен параметр `-EnvironmentPath 'ПУТЬ-К-ОКРУЖЕНИЮ'`; `-SkipInstall` пропускает загрузку уже установленных зависимостей. До сборки всегда выполняются интеграционные проверки. Для сборки из чистого окружения используется сохранённый перечень версий зависимостей.

При переходе к рабочему использованию требуются согласование регламента, проверки нагрузки, защиты и целевой платформы, оценка интеграции с действующими системами и при необходимости перенос на PostgreSQL.
