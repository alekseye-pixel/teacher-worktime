# Автоматизация учёта рабочего времени преподавателя

Учебный программный проект к выпускной квалификационной работе. Программа предназначена для регистрации выполненных работ преподавателей, согласования записей и сопоставления месячного плана с фактическими затратами времени.

Предметная область рассмотрена на примере МУИВ. Демонстрационные кафедры, преподаватели, планы и записи являются вымышленными. Программа не заменяет официальный табель и не начисляет заработную плату.

## Возможности

- регистрация интервалов работы и проверка корректности записей;
- ведение справочников и месячных планов;
- передача записей на согласование, согласование и возврат с комментарием;
- разграничение доступа для администратора, руководителя и преподавателя;
- формирование отчётов в DOCX, XLSX и CSV, импорт записей из CSV;
- поиск, календарь, контроль данных и журнал действий;
- резервное копирование и восстановление базы.

## Технологии

Python 3.12, Tkinter, SQLite, HTTP/HTTPS JSON API, python-docx и openpyxl. Клиент и сервер работают отдельными процессами. По умолчанию сервер доступен по адресу `http://127.0.0.1:8765` на том же компьютере.

## Запуск из исходников на Windows

Установите Python 3.12 с компонентом Tcl/Tk. Откройте PowerShell в каталоге, где находятся `server.py`, `client.py` и `requirements.txt`.

Создайте виртуальное окружение и установите зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для первого запуска с учебными данными запустите сервер:

```powershell
.\.venv\Scripts\python.exe server.py --demo
```

Оставьте это окно открытым. Во втором окне PowerShell из того же каталога запустите клиент:

```powershell
.\.venv\Scripts\python.exe client.py
```

В окне входа используйте адрес `http://127.0.0.1:8765`.

### Демонстрационные учётные записи

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `12345` | Администратор |
| `head` | `DemoTime2026!` | Руководитель |
| `teacher` | `DemoTime2026!` | Преподаватель |
| `teacher2` | `DemoTime2026!` | Преподаватель |

Эти реквизиты предназначены для демонстрационной базы с вымышленными данными.

При следующих запусках используйте существующую базу без параметра `--demo`:

```powershell
.\.venv\Scripts\python.exe server.py
```

## Готовый комплект Windows

В готовом комплекте запуск выполняется файлом `Запустить программу.exe`. Архив необходимо полностью распаковать в доступную для записи папку. Рядом с запускателем должны находиться каталоги `Клиент` и `Сервер` со всем их содержимым.

Запускатель подготавливает демонстрационную базу при первом открытии, выбирает свободный локальный порт, запускает сервер и клиент. После закрытия клиента сервер завершается. Для этого способа запуска нужны готовые EXE и их комплект файлов: наличие одних исходников из репозитория недостаточно.

## Проверки и экономический расчёт

Запуск интеграционных проверок из каталога проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_system.py
```

Воспроизведение сценарного экономического расчёта:

```powershell
.\.venv\Scripts\python.exe economics.py
```

Экономический расчёт основан на проектных допущениях и не отражает фактические финансовые результаты университета.
